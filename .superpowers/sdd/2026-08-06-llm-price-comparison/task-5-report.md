# Task 5 完成报告：应用外壳、筛选栏与价格总表

## 范围与实现

- 建立桌面双栏目录：顶部导航、筛选栏、语义化价格表，以及仅作后续功能布局的对比区域。
- 复用既有 `catalog`、价格标准化、筛选排序与 URL 状态逻辑；未复制领域规则。
- 价格表使用 `<table>`、`<thead>`、列头 `scope`、排序状态和带模型名的对比复选框。未公开价格显示“未公开”。
