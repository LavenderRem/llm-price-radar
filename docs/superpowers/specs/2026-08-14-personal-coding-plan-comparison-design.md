# 个人编程套餐对比设计

## 目标

在「模型价签」中新增个人编程套餐对比页，帮助用户在官方口径下横向比较面向个人的 AI 编程产品及其套餐档位。

页面聚焦月费、计费周期、包含用量、额度与超额规则、编程入口和官方来源。它不替代现有模型 API 单价对比页。

## 范围与纳入规则

- 仅展示官方明确向个人提供 IDE、CLI 或编程 Agent 使用权的套餐。
- 纯通用聊天订阅不纳入；只有当官方明确说明订阅包含独立的编程产品或编程 Agent 权益时，才可纳入该编程套餐。
- 同一产品的免费、Pro、Max 等每个符合规则的档位各占一行。
- 未提供个人编程套餐的服务商不展示。
- 首批核验对象为 OpenAI Codex、Cursor、Claude Code、Gemini Code Assist、Trae 与腾讯 CodeBuddy；是否最终展示由其官方套餐页面决定。

## 页面与交互

新增顶部导航「编程套餐」，视觉采用已确认的「精确数据终端」方向，并延续现有蓝白色、细边框、圆润控件和高信息密度表格风格。

页面主体是一张套餐比较表：

| 列 | 内容 |
| --- | --- |
| 产品 / 套餐 | 产品名称、套餐名称和简短产品类型 |
| 月费 | 原币月费；年付套餐同时显示折算月费与年付说明 |
| 计费周期 | 月付、年付或免费 |
| 包含用量 | 官方披露的请求、信用额度、代理用量或其他原始单位 |
| 额度与超额 | 重置周期、速率限制、超额购买或「未公开」 |
| 编程入口 | IDE、CLI、Agent、代码审查等标签 |
| 官方来源 | 价格页链接与核验状态 |

筛选项包括「全部」「IDE」「CLI / Agent」「免费套餐」，并支持按月费排序。保留现有右侧对比清单，最多选择 3 个套餐并排查看关键字段。

金额沿用现有 CNY / USD 切换。目录保存原始币种与金额；换算只用于展示。未公开的额度、超额规则或限制必须明确显示「未公开」，不得推算或以模型 API 单价替代。

## 数据模型

每个套餐档位是一条结构化记录，至少包含：

- `providerId`、`productName`、`planName`、`planType`；
- `price`（金额、原币种、计费周期、年付折算信息）；
- `includedUsage`（原始说明、数值与单位仅在官方明确时填写）；
- `allowancePolicy`（重置周期、速率、超额或未公开状态）；
- `codingSurfaces`（IDE、CLI、Agent 等）；
- `officialUrl`、`verifiedAt` 与可读的官方说明摘要；
- 用于每日检查的、只含关键事实的价格指纹。

UI 不从网页 HTML 临时解析出套餐内容；展示只读取已核验的目录数据。

## 更新策略

每日工作流读取各产品的官方套餐来源，并把月费、计费周期、包含用量、额度与超额规则、编程入口和官方链接组成套餐价格指纹。

- 只有这些关键事实变化时，才生成更新报告和更新 PR。
- 页面布局、导航、营销文案、时间戳或动态内容变化不应触发价格更新。
- 任何来源抓取或校验失败时，不更新目录、不覆盖现有状态、不创建更新 PR。
- 检查结果应保留来源核验时间；实际页面数据日期仍以目录的 `verifiedAt` 为准。

## 测试与验收

- 对纳入与排除规则编写单元测试，确保纯聊天套餐不会进入目录。
- 测试多档位拆分、缺失字段显示「未公开」、CNY / USD 换算、筛选、排序和最多 3 项对比。
- 测试每日检查仅在关键套餐字段变更时产出更新；非价格网页变化、失败抓取和干跑均不写入数据。
- 运行既有前端测试、价格同步测试和生产构建，确保原有模型价格页面与 GitHub Pages 构建不回归。

## 非目标

- 不抓取或展示纯通用聊天订阅。
- 不根据模型 API 单价估算编程套餐额度价值。
- 不在首次实现中增加账号登录、付费、用户自定义套餐或自动购买功能。
